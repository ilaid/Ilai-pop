## 0. מסגרת הפרויקט
- **מטרה:** מערכת מסחר אוטומטית. שלב נוכחי = דמו + בק-טסט. אם התוצאות טובות → הרצה לפועל.
- **מכשירים:** חוזי מיקרו עתידיים בלבד — **MNQ** (נאסד"ק), **MES** (S&P 500), **MYM** (דאו/YM).
- **סטאק מומלץ:** Python (בק-טסטינג, ניתוח נתונים, חיבור לברוקר). ריבוי-שפות בהמשך לפי צורך.
- **שיטה:** Quarterly Theory של Trader Daye, עם התאמות/תיקונים של המשתמש (מפורטים כאן).

## 1. מבנה זמן פרקטלי (העיקרון המרכזי)
הכל מתחלק ל-**4**, בכל רמה: שנה→4 רבעונים (3 חודשים כ"א) · חודש→4 שבועות · שבוע→4 ימי מסחר (שישי לא נחשב יום מסחר עצמאי) · יום→4 סשנים · סשן→4×90 דק' · 90 דק'→4×22.5 דק'.

**תובנת מפתח:** השבירה/נזילות **בין** תת-יחידות של רמה מסוימת נראית ברזולוציית נר **נמוכה משמעותית**, לא בנר שמייצג את הרבעון עצמו:

| מה נשבר (בין מה למה) | הנר שבו רואים את השבירה/נזילות (SMT) | ה-scope שמושפע |
|---|---|---|
| רבעון שנתי מול רבעון שנתי (3-חודשי) | נר **שבועי** | השנה כולה |
| חודש מול חודש (בתוך אותו רבעון בלבד) | נר **יומי** | הרבעון כולו |
| שבוע מול שבוע (בתוך החודש) | נר **4 שעות** | החודש כולו |
| יום מול יום (בתוך השבוע) | נר **שעתי (1H)** | השבוע כולו |
| סשנים בתוך היום (Asia/London/NY/PM) | נר **15 דקות** | אותו יום מסחר |
| סשן 90 דק' מול 90 דק' | נר **5 דקות** | הסשן |
| בתוך 90 דק' (בין רבעוני 22.5 דק') | נר **1 דקה** | ה-90 דק' |

- "חודש מול חודש" — **רק בתוך אותו רבעון**. אם חודש מסוים לא הגיב, מדלגים עליו (למשל יולי מול ספטמבר). לא חוצים לרבעון הבא.

## 2. Bias היררכי
- רמות גבוהות (שבועי/חודשי/שנתי) קובעות **Bias/כיוון**.
- כניסות בפועל (על MNQ/MES/MYM אינטרה-דיי) נגזרות מרמת **היום ומטה** (15 דק' → 5 דק' → 1 דק').

## 3. True Open = תחילת ה-Q2 של כל רמה (תיקון למסמך המקורי!)
ה-True Open אינו תחילת Q1 (הפתיחה הקלנדרית) אלא **תחילת ה-Q2**:
- מחזור חודשי → True Open = תחילת **שבוע 2**.
- מחזור שבועי → True Open = **יום שלישי** (= יום שני 18:00 EST, שנחשב תחילת שלישי לפי QT).
- מחזור יומי → True Open = **00:00 EST** (פתיחת לונדון). *(המסמך המקורי כתב 18:00 — שגוי.)*
- וכן הלאה לכל רמה נמוכה: Q2 של הרמה = ה-True Open שלה.

## 4. Dealing Range / DOL (Draw On Liquidity)
- ה-Range **דינמי** — נקבע לפי אזור הנזילות הרלוונטי ל-QT הנוכחי (Swing High/Low, נזילות יום/שבוע קודם, FVG פתוח, נזילות ישנה שלא נלקחה). לא כלל קבוע.
- **תגובת מחיר מול DOL:**
  - **דריסה בגוף (Plow through):** גוף שובר וממשיך → הולכים ל-DOL הבא באותו כיוון.
  - **דחייה בפתיל (Wick rejection):** נגיעה/חדירה בפתיל וסגירה בחזרה → אזור חזק, צפי להיפוך עד השבירה הבאה.
  - **Equal Highs/Lows** קרובים זה לזה → מאגר נזילות אחד, מצפים ל-Sweep של שניהם יחד.
- ה-DOL משמש גם כ**יעד (TP)**.

## 5. SMT — לב האסטרטגיה
נבדק בין **שלושת הנכסים** (MNQ/MES/MYM). לכל טווח זמן ה-SMT שלו, מקושר ל-Swing של אותו מחזור (ראה טבלה §1). דוגמה: "שלישי לקח את הגבוה של שני" = בין יום ליום = מיוצג בגרף **שעתי**.

**תזמון אישור קריטי:** SMT הוא **פוטנציאלי** כל עוד מתפתח על טווח נמוך יותר. **מאושר רק בסגירת הנר של הגרף המייצג** את רמת השבירה (יום-מול-יום → סגירת נר שעתי; שבוע-מול-שבוע → סגירת נר 4H; וכו').

**מסנן מיקום מול True Open (קריטי):** SMT (מכל סוג) רלוונטי **ברוב המקרים** רק כשהוא בצד הנכון של ה-True Open של הסייקל שאליו הוא מקושר:
- **SMT לירידות** → רק כשהוא **מעל** ה-True Open (פרימיום) של אותו סייקל.
- **SMT לעליות** → רק כשהוא **מתחת** ל-True Open (דיסקאונט) של אותו סייקל.
- ה-True Open של הרמה הרלוונטית **הוא** קו ההפרדה פרימיום/דיסקאונט (מחבר את "SMT = אישור" ל-PD).

**סולם ה-SMT מול ה-True Open (מאושר):**

| SMT בגרף | מקושר לסייקל | נמדד מול True Open של |
|---|---|---|
| שבועי | שנתי | True Yearly Open (תחילת Q2 שנתי) |
| יומי | רבעוני | True Quarterly Open (חודש 2 של הרבעון) |
| 4H | חודשי | True Monthly Open (שבוע 2) |
| 1H | שבועי | True Weekly Open (שלישי / שני 18:00 EST) |
| 15M | יומי | True Daily Open (00:00 EST / לונדון) |
| 5M | סשן | True Open של הסשן (Q2 = ה-90 דק' השני) |
| 1M | 90 דק' | True Open של ה-90 דק' (Q2 = ה-22.5 השני) |

### 5א. SSMT (מבוסס פתיל)
- נכס אחד לוקח בפתיל Swing High/Low של התקופה הקודמת, נכס אחר לא. **פתיל מספיק.**
- **מספיק נכס אחד** שסוטה (לא צריך רוב).

### 5ב. HSSMT (מבוסס סגירה) — חזק יותר
- מבוסס על **מחיר הסגירה (גוף)**: סגירה מעל מחיר הסגירה הגבוה ביותר / מתחת לנמוך ביותר של אותו סייקל.
- **משתמשים במחיר הסגירה של הנר עצמו** — לא בפתיחת הנר הבא.
- **עדיפות:** קודם בודקים HSSMT. אם שני הנכסים סגרו לאותו כיוון (אין סטיית סגירה) — סטיית פתיל (SSMT) **לא נחשבת**, כי HSSMT גובר. SSMT רלוונטי רק כשאין סתירת HSSMT.

### 5ג. כלל YM (MYM) — אסימטרי / הפוך
YM = הנכס ה**חלש**; מצופה לרדת מהר יותר. חוזק יחסי שלו = סיגנל **היפוך**:
- **סטייה לעליות (Bullish):** ES/NQ עשו שפל נמוך יותר (לקחו נמוך/סגרו נמוך), אך **YM לא** → סיגנל לונג. חזק במיוחד כשהם שברו למטה והוא לא.
- **סטייה לירידות (Bearish):** YM מצליח לקחת גבוה שהם לא לקחו (בפתיל או בסגירה) → SMT חזק לירידות (מלכודת/מיצוי).

### 5ד. SMT Fill (מבוסס FVG) — "גורם מעכב"
- אותו עקרון תזמון כמו SSMT (בין רבעים תאומים לפי הזמן). מבוסס **FVG** שנוצרו באותם זמנים.
- **3 סוגים** (לפי עומק חדירה ל-FVG), רלוונטי ל-3 הנכסים:
  1. נכס אחד נוגע ב-FVG, השני לא נוגע כלל.
  2. נכס אחד נוגע עד ~**50%**, השני נוגע פחות / לא נוגע.
  3. נכס אחד ממלא **בפתיל** עד הסוף / עובר את ה-FVG; השני לא הגיע עם הפתיל / עבר בפתיל בלבד.
- **סוג 3 — כלל תוקף:** רק **פתיל**. הפתיל יכול למלא/לעבור את כל ה-FVG וזה עדיין תקף. **ברגע שהמחיר סוגר בגוף** את ה-FVG והופך אותו ל-**IFVG** → ה-SMT Fill **מתבטל**.

### 5ה. היררכיית זמנים, מהלכים מעכבים וביטול
- ככל שה-SMT בטווח גבוה יותר → חזק יותר, אך השפעתו **מתפרסת על זמן ארוך יותר**.
- דוגמה: SSMT 4H לירידות = ביאס ירידה לכל החודש, **עד** ש(א) נשבר ע"י SSMT/HSSMT 4H הפוך, או (ב) הגענו ל-DOL.
- **מהלך מעכב:** SMT בטווח נמוך בכיוון ההפוך (למשל SSMT 15 דק' לעליות בתוך ביאס 4H לירידות) = **pullback זמני** לצבירת נזילות / הגעה ל-DOL גבוה יותר, ואז חזרה למגמה הגדולה. **לא היפוך ביאס.**
- כשה-SMT הנמוך **נשבר** → מפסיק לעכב ותומך במגמה הגדולה.
- **היפוך ביאס אמיתי** רק כשהטווח הגבוה עצמו נשבר: הנכס שלא לקח את הנמוך/גבוה — **פתאום כן לוקח** → הסטייה נסגרת והופכת לאישור מגמה חדשה.
- **לאוטומציה:** נדרשת **מכונת-מצבים רב-שכבתית** — SMT הגבוה הפעיל קובע ביאס; SMT נמוכים = אירועי pullback/עידון-כניסה, לא היפוך.

## 6. הגדרת FVG (מורחבת)
- בסיס: הפער בנר האמצעי מבין 3 נרות (פתיל נר 1 מול פתיל נר 3).
- **הרחבה ע"י פערי-גוף (Close→Open):** כל פער בין סגירת נר לפתיחת הנר הבא (ולו הקטן ביותר) **מרחיב** את ה-FVG עד מחיר הסגירה הרלוונטי:
  - פער Close נר 1 → Open נר 2 → מרחיב את הגבול בצד נר 1 עד **Close של נר 1**.
  - פער Close נר 2 → Open נר 3 → מרחיב את הגבול בצד נר 3 עד **Close של נר 2**.
  - שתי ההרחבות יכולות לקרות יחד.
- כלומר ה-FVG כולל גם את פערי הגוף, לא רק פער הפתילים. משפיע על מדידת 50% ועל זיהוי IFVG.
- **חידוד לפני בנייה:** לנעול נוסחת גבולות מדויקת (min/max פתיל מול פערי גוף) עם דוגמה מספרית.

## 7. שבירת מבנה: CISD/CHoCH מול MSS
- **CISD / CHoCH (Change of Character)** — סימן מוקדם, "נורת אזהרה". שבירת הנר האחרון בכיוון המגמה שקדם למניפולציה האחרונה (סגירה מעברו). **אמינות נמוכה**, יכול לקרות בפתיל בלבד / להיות Liquidity Sweep. מסמן שהאזור מעניין — לא טריגר.
- **MSS (Market Structure Shift)** — אישור חזק ורשמי. שבירת ה-**Swing המבני האחרון** לפני התנועה הנגדית, עם **Displacement** ו**גוף נר** (לא פתיל). **טריגר הכניסה** — לרוב בהמתנה ל-pullback ל-FVG/OB שנוצר ב-MSS.

## 8. PD Array (Premium/Discount) — בעדיפות נמוכה כרגע
- כל טווח בין שני אזורי סטייה מתחלק ב-50% → פרימיום (מעל, שורט) / דיסקאונט (מתחת, לונג), רקורסיבית.
- **לא רכיב קריטי ב-v1** — נשמר כרעיון משני, לא בונים עליו לוגיקת כניסה כרגע.
